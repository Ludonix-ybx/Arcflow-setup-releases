**Arcflow Protocol** is an AI game guide that lives inside your game. It's a lightweight PC overlay that reads what's on your screen and answers on demand with puzzle solutions, secrets, tactics and lore, so you never have to pause or alt-tab to a wiki.

> This repository hosts the official installers for the Arcflow alpha. The product's source code is private. For features, pricing and the list of supported games, visit [arcflowprotocol.com](https://arcflowprotocol.com).

## Get started

1. **Download** the latest installer from this repository or from the [downloads page](https://arcflowprotocol.com/downloads.html).
2. **Run the setup** and sign in with your Arcflow account.
3. **Launch your game through Arcflow.** The launcher starts the game and the overlay together.
4. **Ask when you're stuck.** Type your question in the overlay or use the hotkey.

## Good to know

- **Platform:** Windows PC
- **Single-player only:** Arcflow is designed for single-player games and does not inject code into your game.
- **Internet connection required:** The AI runs in the cloud.
- **Free trial available:** Plans and pricing are on the website.
- **Supported games:** The library keeps growing, now over 50+ supported titles, full list on our website.
